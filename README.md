# Elysian Engine

The Elysian engine is a lightweight, high-performance game engine built as an escape from the bloat and complexity of mainstream engines such as Unreal, Unity, and Godot.

**Current Features:**
- Deferred renderer with point, spot and directional lights
- Debug markers for lights
- ENTT driven ECS
- Editor gizmos for manipulating entities
- Custom mesh format
- Texture support with custom format
- Optimized Infinite world grid
